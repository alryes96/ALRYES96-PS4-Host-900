# حزمة ALRYES96 — مستودع PS4 Firmware 9.00

## ما الموجود هنا؟
- `index.html`: صفحة تأسيسية عربية للمستودع المستقل `ALRYES96-PS4-Host-900`، وليست سلسلة جلبريك فعالة.
- `SOURCES_AND_LICENSES.md`: سجلّ التحقق المطلوب قبل نقل أي ملفات خارجية.
- `main-site-patch/`: تعديل صغير مخطط لتوجيه إصدار 9.00 فقط إلى المستودع الجديد، مع إبقاء بقية الإصدارات على المسار الحالي.

## خطوات رفع صفحة المستودع
1. افتح `https://github.com/alryes96/ALRYES96-PS4-Host-900`.
2. استخدم Add file → Upload files.
3. ارفع `index.html` و`SOURCES_AND_LICENSES.md` إلى جذر المستودع، ثم Commit changes.
4. من Settings → Pages اختَر Deploy from a branch ثم `main` و`/(root)`.
5. انتظر حتى يصبح رابط Pages متاحاً وافتحه من متصفح الحاسبة للتأكد من ظهور الصفحة قبل تغيير التوجيه.

## تنبيه مهم بخصوص التوجيه
لا تطبّق ملف التوجيه الموجود في `main-site-patch` قبل التأكد أن صفحة Pages للمستودع الجديد منشورة. وحتى بعد النشر، ستعرض الصفحة الحالية صفحة تأسيسية فقط إلى أن تكتمل مراجعة مصدر سلسلة 9.00 وتراخيص كل ملفاتها وتبعياتها.

## لا تحذف أو تستبدل
لا تحذف `g2all/` ولا تستبدل `index.html` الرئيسي أو تصميم الموقع الأصلي. التغيير المخطط يطال ملف `gamerhack-launch.html` فقط وبالأسطر المحددة داخل ملف التوجيه.
